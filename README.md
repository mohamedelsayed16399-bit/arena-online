# ⚔️ ساحة الأبطال — لعبة أونلاين جماعية

لعبة معارك حية في المتصفح: غرف خاصة بكود، لعب سريع مع ناس حقيقية، شات في الانتظار، لوحة متصدرين عالمية، وأصدقاء بكود — كله مجانًا على Firebase + GitHub Pages.

## العب دلوقتي
https://mohamedelsayed16399-bit.github.io/arena-online/

## إزاي تلعب
- 🎯 اقتل أكتر عدد من اللاعبين قبل ما الوقت يخلص (٣ دقايق).
- 🖥️ كمبيوتر: حركة WASD/أسهم + تصويب بالماوس + كليك للضرب.
- 📱 موبايل: عصا شمال للحركة وعصا يمين للتصويب (بتضرب لوحدها).
- 🛡️ كل لاعب ١٠٠ نقطة دم، الطلقة ٢٥. الموت = رجوع بعد ٣ ثواني.


## المميزات
- ⚔️ أوضاع: كلاسيك (٣ دقايق)، ⚡ بليتز (٦٠ ث)، 🎯 السيطرة على المنطقة (٩٠ ث)، 🌪️ العاصفة المتضيّقة (٩٠ ث).
- 🤖 لو انت لوحدك: وضع الموجات ببوتات (٣ مستويات صعوبة)، براميل متفجرة، وزعيم كل ٥ موجات (زعيم الانفجار من الموجة ١٠).
- 💨 داش (Space/Shift) و 💣 قنبلة يدوية (G) بكولداون، وقدرات: صحة، تسريع، درع، رشاش، ثلاثي، شوتجن.
- 🗺️ ٤ خرايط (ليل، صحرا، تلج بجليد بينزلق، حمم بتجرح) + حيطان متحركة + خريطة صغيرة.
- 🏅 إنجازات (٩) في الجهاز، 📊 شاشة أداء بعد كل جولة بأوسمة، 👁️ مشاهدة بعد الموت، رد فعل إيموجي، ريماتش.
- 🏆 متصدرين، 👥 أصدقاء بكود، 🚪 غرف عامة، 💬 شات.
- ✨ جزيئات وهزّة شاشة وأثر حركة وأصوات WebAudio.

## ملاحظة
البوتات والبراميل والزعماء محلية على جهاز اللاعب الوحيد (مش بتتزامن). الحيطان المتحركة والحمم والجليد والعاصفة والخرايط محسوبة من seed الغرفة فبتتطابق عند كل اللاعبين.
