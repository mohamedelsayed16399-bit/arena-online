# ⚔️ ساحة الأبطال — لعبة أونلاين جماعية

لعبة معارك حية في المتصفح: غرف خاصة بكود، لعب سريع مع ناس حقيقية، شات في الانتظار، لوحة متصدرين عالمية، وأصدقاء بكود — كله مجانًا على Firebase + GitHub Pages.

## العب دلوقتي
https://mohamedelsayed16399-bit.github.io/arena-online/

## إزاي تلعب
- 🎯 اقتل أكتر عدد من اللاعبين قبل ما الوقت يخلص (٣ دقايق).
- 🖥️ كمبيوتر: حركة WASD/أسهم + تصويب بالماوس + كليك للضرب.
- 📱 موبايل: عصا شمال للحركة وعصا يمين للتصويب (بتضرب لوحدها).
- 🛡️ كل لاعب ١٠٠ نقطة دم، الطلقة ٢٥. الموت = رجوع بعد ٣ ثواني.


## المميزات
- ⚔️ أوضاع: كلاسيك (٣ دقايق)، ⚡ بليتز (٦٠ ث)، 🎯 السيطرة على المنطقة (٩٠ ث)، 🌪️ العاصفة المتضيّقة (٩٠ ث).
- 🤖 لو انت لوحدك: وضع الموجات ببوتات (٣ مستويات صعوبة)، براميل متفجرة، وزعيم كل ٥ موجات (زعيم الانفجار من الموجة ١٠).
- 💨 داش (Space/Shift) و 💣 قنبلة يدوية (G) بكولداون، وقدرات: صحة، تسريع، درع، رشاش، ثلاثي، شوتجن.
- 🗺️ ٤ خرايط (ليل، صحرا، تلج بجليد بينزلق، حمم بتجرح) + حيطان متحركة + خريطة صغيرة.
- 🏅 إنجازات (٩) في الجهاز، 📊 شاشة أداء بعد كل جولة بأوسمة، 👁️ مشاهدة بعد الموت، رد فعل إيموجي، ريماتش.
- 🏆 متصدرين، 👥 أصدقاء بكود، 🚪 غرف عامة، 💬 شات.
- ✨ جزيئات وهزّة شاشة وأثر حركة وأصوات WebAudio.

## ملاحظة
البوتات والبراميل والزعماء محلية على جهاز اللاعب الوحيد (مش بتتزامن). الحيطان المتحركة والحمم والجليد والعاصفة والخرايط محسوبة من seed الغرفة فبتتطابق عند كل اللاعبين.

## التقنيات
- HTML5 Canvas + JavaScript خالص (بدون مكتبات)
- Firebase Realtime Database للمزامنة اللحظية
- Firebase Anonymous Auth
- خط Cairo من Google Fonts

## تحديثات الجولات 33 إلى 43
- وضع الزعماء المتتالية (Boss Rush) ولوحة متصدرين لأفضل موجة، وتعديلات الموجات (ظلام، سرعة، غضب، غنيمة، سرب)
- ٣ خرايط جديدة: 🌲 غابة، 🌐 نيون، 🌊 عميق (٨ خرايط كلهم)
- كومبو القتل: قتلتين أو أكتر في ٤ ثواني = بانر (ثنائية/ثلاثية/رباعية/مجزرة) + عملات وشحن للقدرة
- موت الزعيم: حركة بطيئة ١.٣ ثانية + موجات انفجار + اهتزاز
- زعيم الجليد (موجة ٢٥): برك تجمّد بتبطّأك وهجوم اندفاعي بخط تحذير أحمر
- غنيمة الزعيم: سلاح الليزر المخترق ١٥ ثانية + صحة
- وضع فريق ضد فريق 🔴🔵 (لاعبين حقيقيين، بدون ضرر على الفريق، نتيجة فريق)
- وضع التعاون 🤝 ضد الموجات والزعماء (كل لاعب بموجاته، من غير ضرر على صاحبك)
- نظام خبرة ومستويات بعد كل جولة، وعملات هدية عند الترقية
- إصلاح: الاسم بيرجع صح بعد انقطاع الاتصال
- شرح لأول مرة تلعب (Tutorial) وملخص الموت (مين قتلك + نصيحة)
- زعيم الهيدرا (موجة ٣٠): دوامات طلقات وبيتقسم لراسين لما يموت
- زعيم البرق (موجة ٣٥): بيعلّم دواير صفرا وبعد ثانية ونص الصاعقة بتضرب — اتحرك!
- 👹 سيد الساحة (موجة ٤٠): بيجمع دوامات الهيدرا مع صواعق البرق، ٢٠٠٠ صحة — ولما صحته تنزل للنص بيغضب وبيسرّع هجماته
- ٣ خرايط جديدة: 🌲 غابة، 🌐 نيون، 🌊 عميق (٨ خرايط كلهم)
- كومبو القتل: قتلتين أو أكتر في ٤ ثواني = بانر (ثنائية/ثلاثية/رباعية/مجزرة) + عملات وشحن للقدرة
- موت الزعيم: حركة بطيئة ١.٣ ثانية + موجات انفجار + اهتزاز
- سلاح قاذف اللهب 🔥 (ضد البوتات)
- وضع الاستحواذ على العلم 🚩 (مزامنة Firebase: أول واحد يمسك العلم، نقطة كل ثانية، لو اتقتلت العلم بيقع)
- 🧲 علبة المغناطيس: ١٠ ثواني بتجذب كل العلب في دايرة كبيرة
- 🕷️ ملكة الأسراب (موجة ٤٥): بتتنقل وبتستدعي أتباع مع دوامات، ٢٦٠٠ صحة (٩ زعماء في زعماء الزعماء)
- ♾️ بعد موجة ٤٥: كل زعيم بيزيد ١٥٪ صحة كل ٥ موجات
- أرقام الضرر بتطلع فوق البوتات لما تضربها (الأصفر = ضربة قوية)
- 🚁 علبة درونين مساعدين ١٥ ثانية
- رقم أحمر فوقك لما تتضرب (كام صحة نزلت)
- 💣 لعبة القنبلة (٩٠ ث): قنبلة مع لاعب واحد، بتتمرر باللمس، بتنفجر بعد ١١-١٧ ث (-٧٠ صحة) وبعدين بتروح للاعب تاني. نقطة كل ثانية لمن مفيش معاه القنبلة
